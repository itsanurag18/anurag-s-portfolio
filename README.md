# Anurag's Digital Canvas

Build a premium, modern developer portfolio for Anurag inspired by the clean, minimal polish of Linear, Vercel, and Apple. Dark theme, high-contrast typography, generous whitespace, subtle borders, and soft ambient glows.

Structure and features:
1. Floating sticky glassmorphism navbar with smooth scrolling to sections (About, Experience, Projects, Skills, Certifications, Contact) and mobile drawer.
2. Hero section:
   - Eyebrow tag: "SOFTWARE DEVELOPER • BUILDER • PROBLEM SOLVER"
   - Status badge: "Currently learning & building" with pulsing indicator
   - Headline: "Building modern digital experiences with code."
   - Subtitle: "I build thoughtful, scalable and user-focused digital experiences while continuously learning and exploring modern technologies."
   - CTAs: "View My Work" (scrolls to projects) and "Let's Connect" (scrolls to contact)
   - Tasteful background glow / mesh grid.
3. About section ("More than just code."): authentic developer philosophy, current technical focus, and highlight cards.
4. Experience / Journey section: sleek vertical timeline with dates, roles/milestones, organizations, and descriptions.
5. Projects showcase: Apple-style bento grid featuring a hero project card and supporting cards, with live demo links, GitHub links, tech tags, and subtle hover interactions.
6. Skills dashboard: categorized into Frontend, Backend, Database, Tools, and AI / Dev Tools with modern badge cards (no progress bars).
7. Certifications & Stats: credentials showcase and key metrics (Projects, Technologies, Hours of Coding, Certifications).
8. Contact section: "Have an idea? Let's build it.", social links (GitHub, LinkedIn, Email), and a sleek contact form UI with toast feedback.
9. Minimal footer with developer tagline, quick links, and copyright.
10. Centralized data configuration file (e.g., `src/data/portfolio.ts`) containing all user profile details, projects, skills, timeline items, and stats so Anurag can effortlessly swap out placeholder data with real content. Fully responsive and accessible.
